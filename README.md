# Omniverse WordPress Theme

## Description

Omniverse is a premium WordPress theme designed for versatile and modern websites. It offers a comprehensive set of features including WooCommerce integration, Elementor page builder support, and a powerful header builder for creating stunning, customizable layouts.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **WooCommerce Integration**: Complete e-commerce functionality with custom product layouts
- **Elementor Support**: Drag-and-drop page building with optimized Elementor styles
- **Header Builder**: Customizable header elements including logo, menu, search, cart, and more
- **Portfolio Support**: Dedicated portfolio post type with various display options
- **Multilingual Ready**: WPML configuration for international websites
- **RTL Support**: Right-to-left language support
- **Custom Post Types**: Support for layouts, slides, and CMS blocks
- **Theme Options**: Extensive customization options via theme settings
- **SEO Optimized**: Clean code and semantic markup for better search engine rankings

## Requirements

- WordPress 5.0 or higher
- PHP 7.4 or higher
- WooCommerce (for e-commerce functionality)
- Elementor Page Builder (recommended)

## Installation

1. Download the theme zip file from ThemeForest
2. Log in to your WordPress admin dashboard
3. Go to **Appearance > Themes**
4. Click **Add New** and then **Upload Theme**
5. Choose the theme zip file and click **Install Now**
6. After installation, click **Activate** to activate the theme

## Recommended Plugins

- WooCommerce
- Elementor
- WPML Multilingual CMS (for multilingual sites)
- Contact Form 7 (for contact forms)

## Theme Setup

After activating the theme:

1. Go to **Omniverse > Theme Options** to configure general settings
2. Use the **Header Builder** to customize your site's header
3. Set up WooCommerce if you're running an online store
4. Import demo content if desired (available via theme options)

## Customization

The theme offers extensive customization options:

- **Theme Options**: Access via **Omniverse > Theme Options**
- **Header Builder**: Customize header layout and elements
- **Elementor Integration**: Use Elementor for page building
- **Custom CSS**: Add custom styles via theme options
